# Obsidian 融合配色与 DeepSeek 来源修复设计

## 背景

Dashboard 当前使用大面积紫色与粉紫背景，和 Obsidian 以白色或主题表面为主的界面存在割裂。用户希望改用薄荷绿与桃色，但保持克制，避免插件变成独立网页或退化为单调的全白页面。

首次真实 DeepSeek 生成已经证明 API Key、SecretStorage、网络请求和模型调用正常。失败发生在本地响应校验阶段：模型返回的单条行动 `sources` 数组超过当前 5 项上限，解析器在去重前直接拒绝响应，Dashboard 显示“行动建议来源必须为 1 到 5 项”。

## 目标

- Dashboard 继承 Obsidian 原生表面和文字颜色，只用薄荷绿建立品牌强调，用桃色表达提醒与错误。
- 保持当前顶部横向导航、完整内容宽度和现有功能行为。
- 让重复来源不会导致有效 DeepSeek 响应被拒绝，同时继续拒绝未知或编造来源。
- 不扩大发送给 DeepSeek 的知识库内容，不记录或暴露 API Key 与原始模型响应。

## 配色方案

| 色值 | 用途 |
|---|---|
| `#5CCEC4` | 主要强调色：当前导航、主按钮、关键指标和 Hero 起始色 |
| `#8AE7DC` | 柔和强调色：Hero 结束色、悬停状态和浅薄荷分区 |
| `#FFE0CA` | 普通提醒：过期建议、辅助状态和低风险提示 |
| `#FFB8B8` | 错误与高关注状态 |

### 表面层级

- 页面外围和主要卡片使用 Obsidian `--background-primary`、`--background-secondary`、`--background-modifier-border`，不硬编码纯白背景。
- Dashboard 内容分区在 Obsidian 表面上叠加低占比 `#8AE7DC`，形成可感知但克制的浅薄荷区域。
- Hero 使用 `#5CCEC4` 到 `#8AE7DC` 的渐变，不再使用紫色。
- 当前导航使用浅薄荷背景、`#5CCEC4` 边框和主题文字；普通导航继续使用 Obsidian 表面。
- 桃色不用于普通卡片铺色，只用于 stale、warning、error 和少量状态标签。
- 深色主题继续由 Obsidian 表面变量决定背景；薄荷色和桃色以透明混合或边框形式出现，避免大面积高亮。

## DeepSeek 来源修复

### 根因

当前 `parseSources()` 在任何规范化之前执行：

```text
原始数组长度检查 -> 字段检查 -> 白名单检查
```

上下文实际只有有限的允许来源，但模型可能重复引用相同来源。重复项导致原始长度超过 5，即使去重后仍是合法的白名单子集，也会被提前拒绝。Prompt 同时没有明确要求来源唯一。

### 修复后的数据流

```text
原始 sources
  -> 校验为非空字符串
  -> trim
  -> 按名称去重
  -> 校验唯一来源数量为 1–5
  -> 校验每项属于 context.sourceTypes
  -> 保存规范化来源
```

- Prompt 明确要求每条行动的 `sources` 必须是 `context.sourceTypes` 的唯一子集，最多 5 项。
- 重复来源去重后合法则接受。
- 未知来源、空来源、超过 5 个不同来源仍拒绝。
- 不保存原始模型响应，不在错误信息中加入知识库内容或 Secret。
- 本轮不增加自动重试；先修复已证实的解析边界，避免为未知错误扩大 API 调用次数。

## 测试与验收

### 自动测试

- 来源数组包含 6 个重复白名单值时，去重后成功解析为 1 项。
- 来源数组包含未知值时仍失败。
- 来源数组包含 6 个不同允许值时仍失败。
- Prompt 包含“唯一子集”和 `context.sourceTypes` 约束。
- CSS 契约包含四个新色值，并不再包含旧紫色调色板。
- 全量 TypeScript 与 Vitest 检查通过。

### Obsidian 回归

- 浅色主题中页面仍以 Obsidian 表面为主，薄荷色只用于 Hero、选中状态和浅分区。
- 深色主题中表面跟随主题，文字可读，没有大面积发亮色块。
- stale 使用 `#FFE0CA`，error 使用 `#FFB8B8`，普通卡片不使用桃色铺底。
- 使用当前 Secret 生成行动时，不再因重复来源超过原始长度而报错。
- Settings、固定标签、启动焦点和数据源隐私行为保持不变。

## 范围边界

- 不修改目录结构、数据源白名单、用户画像授权范围或 API Key 存储方式。
- 不引入新的主题设置或自定义颜色选择器。
- 不记录 DeepSeek 完整响应，不为调试读取用户凭据笔记。
