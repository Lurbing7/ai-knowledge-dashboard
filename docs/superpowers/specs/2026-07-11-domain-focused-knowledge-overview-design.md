# Domain 聚焦式知识领域概览设计

## 背景

当前 Dashboard 的“知识领域概览”实际并列展示 Inbox、Domain、Projects 和 Wiki。它解决了目录数量与最近笔记的可见性，但存在两个语义问题：

1. Inbox、Projects、Wiki 不是 Domain 内的可复用知识领域。
2. 四张卡片同时展开仍然偏向库存统计，不能快速回答“最近在使用哪个知识领域、相关笔记是什么”。

本次调整把该区域改为 Domain 内部的聚焦式浏览器。它只展示配置的 Domain 目录下一级知识领域，例如 IT、AI、Finance、Business；顶部 Action Guide、Projects、Inbox、Knowledge Map、Wiki、Health 等全局导航保持不变。

## 目标

- “知识领域”名称与内容一致，只展示 Domain 的直接子领域。
- 默认聚焦一个领域，在主体中稳定展示三篇最近笔记。
- 桌面端通过默认收缩、悬停覆盖展开的领域栏减少横向占用，展开时不挤压主体。
- 在窄内容区、触控设备和未来大屏低缩放环境中保持可用。
- 只使用本地 Vault 可验证数据，不把文件更新推断成掌握程度或学习进度。
- 不依赖 DeepSeek，不增加知识库维护任务。

## 非目标

- 不修改 Dashboard 顶部全局导航。
- 不控制 Obsidian 原生左右侧栏。
- 不计算掌握程度、复习进度、知识健康分或遗忘程度。
- 不根据用户画像或 AI 推断活跃领域。
- 不新增 Domain 目录或调整知识库结构。

## 信息结构

“知识领域”组件由两个部分组成：

1. **领域选择栏**：列出 Domain 的直接子目录，按最近笔记修改时间从新到旧排列。
2. **聚焦领域主体**：只展示当前选择领域的可靠摘要。

聚焦领域主体固定展示：

- 领域名称。
- Markdown 笔记总数，作为次要信息。
- 最近活动时间，明确表示文件活动，不表示已经学习或掌握。
- 最近活动位置：从最近笔记相对该领域的目录路径中提取；没有子目录时显示领域根目录。
- 最近三篇 Markdown 笔记：完整标题 tooltip、最多两行可见标题、相对修改时间。
- “进入 `<领域>` →”入口。

领域选择栏收缩时只展示稳定的短标识；展开时展示完整名称、笔记数和最近活动时间。短标识规则固定为：名称不超过三个字符时转为大写并完整显示，超过三个字符时显示第一个字符的大写形式；完整名称始终写入 tooltip 和可访问名称。

## 数据模型与扫描

在本地快照中新增独立的领域摘要，而不是复用目前聚合整个 Domain 的 `AreaSummary`：

```ts
interface DomainSummary {
  name: string;
  path: string;
  count: number;
  latestMtime: number | null;
  recentLocation: string;
  recentNotes: RecentNote[];
}
```

扫描规则：

1. 读取设置中启用的 Domain 根目录。
2. 只把 Domain 根目录的直接子目录识别为领域。
3. 对每个领域递归统计 Markdown 文件；附件和空目录不计入笔记数。
4. 每个领域按 `mtime` 降序保留三篇最近笔记。
5. `latestMtime` 取第一篇最近笔记时间；空领域为 `null`。
6. 领域排序为：有笔记的领域按 `latestMtime` 降序，空领域按名称稳定排序并置后。
7. `recentLocation` 从最新笔记相对领域根目录的父目录生成；它只是活动位置，不尝试生成主题标签。

扫描由现有 Vault 刷新流程驱动。领域数据变化时只更新摘要，不调用 DeepSeek。

## 聚焦状态

采用“首次自动、之后记忆”的规则：

1. 插件没有已保存选择时，聚焦排序后的第一个非空领域；全部为空时聚焦第一个领域。
2. 用户点击领域后，保存该领域路径作为本地 Dashboard 偏好。
3. 后续打开 Dashboard 时优先恢复保存的领域，不因其他领域出现更新而自动跳转。
4. 保存的领域已经删除、移出 Domain 或被禁用时，回退到首次选择规则并覆盖无效值。
5. 保存值属于本地 UI 偏好，不展示在 Settings 页面，不发送给 DeepSeek。

实现上在插件本地设置中增加可选 `focusedDomainPath`，由 Dashboard controller 提供保存入口。该值继续保存在被 Git 忽略的插件本地 `data.json` 中。

## 桌面交互

- 组件内部使用 54px 的收缩领域栏，主体始终为剩余宽度。
- 鼠标悬停领域栏时，它以绝对定位向右覆盖展开至 210px；主体宽度和排版不变化。
- 鼠标离开领域栏后自动收缩。
- 鼠标点击领域后更新主体，但不能因普通点击焦点导致侧栏保持展开。
- 键盘 Tab 产生的 `:focus-visible` 焦点允许领域栏保持展开，便于看清完整名称；焦点离开后收缩。
- 领域按钮使用真实 `button` 和可访问名称；当前领域暴露选中状态。
- 展开与收缩动画固定为 160ms，并遵守 `prefers-reduced-motion`。

## 响应式规则

响应式只依据“知识领域”组件或 Dashboard 主内容容器的 CSS 像素宽度，不读取 Windows 缩放比例、物理分辨率或整个应用窗口宽度。

- **可悬停且内容容器不窄于 680px**：使用收缩领域栏和 hover overlay。
- **内容容器窄于 680px，或设备不支持 hover**：隐藏侧栏，使用顶部横向领域选择器；可横向滚动，不压缩领域名称。
- **未来大屏或较低缩放**：保持相同三篇笔记和侧栏交互；领域组件最大宽度为 980px，避免文本行和卡片无限拉长。
- 屏幕变化只改变排版，不改变最近笔记数量和排序，避免同一状态在不同设备上出现不同信息集合。

## 导航行为

- 点击最近笔记沿用插件现有行为，在新的 Obsidian 标签页打开笔记。
- 点击“进入领域”切换到现有 Knowledge Map 页面，并将对应领域卡片标记为当前领域、滚动到可见位置；不新增重复页面层级。
- Dashboard 首屏顺序保持：下一步行动建议 → 知识领域。
- 原 Inbox、Projects、Wiki 概览卡片从 Dashboard 首页移除，但对应顶部导航和页面不删除。

## 空状态与错误处理

- Domain 数据源未启用：显示“Domain 数据源未启用”，不渲染空选择栏。
- Domain 路径不存在：使用现有配置错误样式显示路径问题。
- Domain 存在但没有直接子目录：提示“Domain 下暂无知识领域”，提供进入 Knowledge Map 或设置检查入口。
- 某个领域为空：领域仍可选择，主体显示“暂无 Markdown 笔记”，笔记数为 0。
- 最近笔记在点击前已被移动或删除：保持页面稳定并显示轻量提示，下一次 Vault 刷新后更新摘要。
- 保存的聚焦路径无效：静默回退并保存有效值，不产生阻断提示。

## 代码边界

- `src/types.ts`：新增 `DomainSummary`，并在 `LocalSnapshot` 中增加领域摘要数组；本地设置增加可选聚焦路径。
- `src/data-sources.ts`：负责按 Domain 直接子目录分组、统计、排序和限制最近三篇笔记。
- `src/dashboard-store.ts` 与 controller：保持快照刷新职责，并提供聚焦路径持久化入口。
- `src/views/dashboard-view.ts`：只负责领域选择状态、DOM 渲染和点击行为，不自行重复扫描 Vault。
- `src/styles.css`：负责 overlay rail、focus-visible、容器响应式与 reduced-motion。

不为了本次功能拆分无关页面或重构 DeepSeek 数据流。

## 测试与验收

### 数据测试

- Domain 直接子目录被正确分组，嵌套目录文件计入所属直接子领域。
- 每个领域最多返回三篇最近笔记，按 `mtime` 降序。
- 有内容、空领域以及相同时间下的排序稳定。
- 最近活动位置从相对路径正确生成。
- Domain 禁用、缺失或没有子目录时返回明确状态。

### 状态测试

- 无保存值时选择最近活动领域。
- 有有效保存值时恢复该领域，不随其他领域更新跳转。
- 保存值无效时回退并保存新值。
- 聚焦路径只留在本地设置，不进入 DeepSeek action context。

### 视图契约

- Dashboard 不再渲染 Inbox、Projects、Wiki 的首页概览卡片。
- 桌面领域栏存在收缩宽度、绝对定位覆盖层和 `:focus-visible` 支持，不使用会导致鼠标点击后粘住的 `:focus-within`。
- 容器窄于 680px 或 `hover: none` 时出现横向领域选择器。
- 聚焦主体固定渲染三篇最近笔记和进入领域入口。
- `prefers-reduced-motion` 下禁用或收敛展开动画。

### 手动验收

1. 在 Obsidian 左右原生侧栏常开时，Dashboard 中间内容不被领域栏展开挤压。
2. 鼠标移入领域栏时覆盖展开，移出后自动收缩。
3. 鼠标点击领域后侧栏不会粘住；键盘聚焦时完整名称仍可见。
4. 切换领域后刷新或重开 Obsidian，恢复上次选择。
5. 缩窄中间内容区时出现横向选择器；大屏低缩放时主体不无限拉宽。
6. 最近笔记和“进入领域”入口可正常打开对应内容。

## 停止条件

- 领域概览只展示真实 Domain 子领域。
- 数据、聚焦记忆、overlay 交互和窄屏替代均有测试覆盖。
- 完整类型检查、测试、构建与本地安装通过。
- 不新增 AI 调用，不泄露本地聚焦偏好，不引入新的知识库维护任务。
